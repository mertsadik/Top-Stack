GRAFIKLER (Kenney)
------------------
Kaynak : Kenney (https://kenney.nl)
Lisans : Creative Commons CC0 1.0 (kamu malı, ticari kullanım serbest, atıf zorunlu değil)

  Textures/pattern.png   <- Pattern Pack / PNG/Default/pattern_02.png
                            (https://kenney.nl/assets/pattern-pack)
                            Arka plandaki ince çapraz çizgiler için.

  UI/panel.png           <- UI Pack / PNG/Grey/Default/button_square_depth_flat.png
                            (https://kenney.nl/assets/ui-pack)
                            9 dilime bölünmüş yuvarlak köşeli panel; seviye hapı,
                            ilerleme çubuğu ve bitiş kartı bundan üretiliyor.
  UI/star.png            <- UI Pack / PNG/Yellow/Default/star.png
  UI/star_bos.png        <- UI Pack / PNG/Grey/Default/star.png

  Particles/star.png     <- Particle Pack / PNG (Transparent)/star_01.png

                            Mükemmel yerleştirmedeki yıldız patlaması.
  Particles/circle.png   <- Particle Pack / PNG (Transparent)/circle_05.png
                            Seviye sonundaki konfeti.

ÇIKARILAN ASSETLER
------------------
İlk sürümde ambientCG'den (CC0) foto-gerçekçi ahşap/taş/metal/mermer dokuları
kullanılıyordu. Casual bir mobil oyun için fazla soluk durduğundan çıkarıldı;
yerine düz canlı renkler + Kenney'in vektörel arayüz/parçacık grafikleri geldi.

CC0 assetler için atıf zorunlu değildir, yine de kaynaklar burada listelenmiştir.

ayrı bir ürün olarak satmak yasaktır.
